Política de Privacidade – Localização (FamLink)

1. Coleta de Dados de Localização

O aplicativo FamLink coleta dados de localização geográfica com o objetivo exclusivo de fornecer funcionalidades de rastreamento familiar em tempo real. Essa coleta ocorre apenas com o consentimento explícito do usuário, e somente enquanto os recursos de rastreamento estiverem ativados.

2. Tipos de Permissões Solicitadas

  • Localização em primeiro plano: para rastrear a posição enquanto o app está em uso.
  • Localização em segundo plano: para continuar o rastreamento mesmo quando o app estiver fechado ou em segundo plano.

3. Armazenamento dos Dados

As informações de localização são armazenadas com segurança na plataforma Firebase, exclusivamente para visualização por usuários autorizados da família.

  • Os dados são mantidos por um período máximo de 3 meses.
  • Após esse período, os dados são automaticamente apagados.

4. Compartilhamento com Terceiros

O FamLink não compartilha dados de localização com terceiros. Todas as informações são utilizadas estritamente para o funcionamento do aplicativo.

5. Controle do Usuário

  • Revogar permissões nas configurações do dispositivo.
  • Desativar o rastreamento no app.
  • Solicitar exclusão antecipada de dados entrando em contato com o suporte.

6. Segurança dos Dados

O app utiliza criptografia e autenticação segura para proteger as informações enviadas e armazenadas.
