Privacy Policy – Location Data (FamLink)

1. Location Data Collection

The FamLink app collects geographic location data solely to provide real-time family tracking features. Data is collected only with the user’s explicit consent and only while tracking is enabled.

2. Types of Permissions Requested

  • Foreground location: to track position while the app is in use.
  • Background location: to continue tracking even when the app is closed or in the background.

3. Data Storage

Location data is securely stored using Firebase, and is only visible to authorized family members.

  • Data is retained for a maximum of 3 months.
  • After this period, it is automatically deleted.

4. Data Sharing

FamLink does not share location data with third parties. All information is used solely for in-app functionality.

5. User Control

  • Users can revoke location permissions at any time in system settings.
  • Tracking can be disabled directly in the app.
  • Early data deletion can be requested via support.

6. Data Security

The app uses secure authentication and encryption to protect all transmitted and stored data.
